# 模糊小文字、标识和图标

用户已授权：截图过小、模糊、笔画丢失时，主动识别并还原清晰版本。按识别、找参考、重建、实际看图的顺序处理；最终材料差异要明确记录。

- 先实际查看原始像素和单独 PSD 图层，读准中文字、英文、副标题、数字及标识结构。放大图只用于观察；放大或锐化不等于恢复丢失的笔画。
- 优先复用同图、同项目中更大的同款素材，或查找官网提供的清晰原版。对照年代、图形、中文字形和英文副标题；旧海报不替换成不同设计的新版标识。
- 普通小文字重排为可编辑文字；纯色标识、数字和规则图标重建完整矢量。品牌专用字形保持其造型，不能把普通字体替换称为官方原版。确需按已辨认文案重绘时，记录字体和近似差异。
- 缺少清晰来源时，根据可靠的文字、外轮廓和重复结构补绘。纹理图标按 ImageGen 编辑流程处理。完全看不清的细节标为推断，不编造品牌、字句或装饰。
- 不把模糊白字的颜色阈值当成最终字形。细线、孔洞、独立小字不能丢掉；关闭遮挡层后资产应完整。
- 清晰版本保持原画面的位置、比例、颜色和遮挡关系，修复脚本也要更新，避免重新生成时恢复旧的模糊描边。
- 实际查看独立 PNG、深浅底和 PSD 回读图，在原显示尺寸及放大状态逐字检查。确认没有断笔、残点、背景碎片或错误英文。

来源 PNG、SVG 和必要的网页引用存于项目内；在 `02_结构` 记录参考 URL、使用版本、文字内容、重建方式与仍属近似的部分。矢量验收参照完整的新底稿，不拿原图里已丢失的笔画去否定合理补全。
