# 美术版 20261102 与拾界独立服务深度对比

比较日期：2026-11-03。来源为下载目录的 `AI拆图助手_便携分享版_20261102`；共同祖先为桌面 `拾界_便携分享版`；服务基线为 `cd0f41d`。源包及祖先目录未修改。

## 结论

美术版的主要增量是原画标注、连续助手、指定对象拆层和候选对比，能够把“框出对象—讨论要求—确认生成—对照应用”串起来。它仍使用生成模型重建素材，不是像素无损拆层，也不能仅凭新保真提示就认定画质稳定。独立服务已有的公司登录、每用户凭据、任务恢复、保真校准与完整实体检查，应在合并时保留。

逐路径比较得到 108 个新增、66 个变化、67 个相同、3 个仅换行变化、14 个拾界独有路径。新增数量包含开发源码与运行副本，不能理解为 108 项功能。66 个变化中，25 个仅上游变化、15 个仅拾界变化、26 个双方变化；后者采用三方合并与针对性回归，未整包覆盖。

## 功能变化与合入方式

| 领域 | 美术版增量 | 拾界合并后的行为 |
|---|---|---|
| 原画标注 | 画笔、矩形、椭圆、套索；24 色及自选色；对象命名、保留/删除、移动缩放 | 原图与单图片层均可标注，源哈希与原生坐标绑定；保存、撤销时保留，导出不烘焙标线；限制对象、笔迹与点数 |
| 连续助手 | 对话历史、当前图层上下文、流式回复、讨论与生成动作 | 接入持久队列；分析不要求生图权限；讨论结束后显式确认，过期、取消或选区变化的结果不得应用 |
| 模型来源 | 理解模型与生图来源独立选择；太石、亿创 Matrix 通道 | 保留 Codex／公司 Agent 自动优先级；新增连接按用户加密，提交时固定来源，通过标准输入传递凭据 |
| 指定拆层 | 明确清单、从后向前顺序、不强行追加背景 | 新增服务端 assistant-split 模式；只生成指定层；中途失败保留已生成层和任务原图 |
| 已有层再拆 | 对选中素材继续细分 | 新层保持原位与父组关系，归档旧版本，不重置整个工程的初始基线 |
| 候选确认 | 主画布左右对照、缩放平移、确认/放弃 | 候选不直接覆盖工程，应用可撤销；拒绝对已改变的工程回填迟到结果 |
| 独立提取 | 按对象或选区生成透明素材，下载或加入图层 | 保留原图、独立候选和透明通道检查；不会把原图裁切冒充实际生成 |
| 去件与补绘 | 彩色标注区分删除、保留；完整实体越过旧框补绘 | 标线只用于语义提示；允许扩大透明画布，保留原有实体归属、边界与局部修复逻辑 |
| 背景与扩建 | 清除 UI、补全不透明背景、上下扩建；组合操作一次请求 | 纯扩建时原图中间区域逐像素贴回；组合去 UI＋扩建允许重绘遮挡区；透明背景或异常比例拒绝应用，不自动重发 |
| 参考创作 | 共享颜色、材质、比例、文字保真要求；2:1 画幅 | 统一进入规划及实际生图请求，后端补齐 2048×1024 参数支持；提示词保真不等于像素锁定 |
| 保存与恢复 | 实际源码新增编辑后延迟自动保存 | 800ms 防抖，保存失败保留脏状态；继续保留版本冲突、目录切换保护及手动保存；加载和选择不触发写盘 |
| 图层交互 | Alpha 命中、低透明辉光、图片缩略图、可调侧栏、宽工程库 | 合并到既有工作台，保留原生文字、矢量、字体与各类导出 |
| 后台任务 | 上游并发任务与临时结果 | 改为两个持久队列执行槽，同 Codex 账号、同工程、本机 GPU 互斥；服务重启不会自动重放收费请求 |
| 构建维护 | 新版提供更多未打包开发源文件 | 源模块与运行副本统一由 `npm run build` 生成；仅新增开发依赖 esbuild，服务运行不依赖它 |

## 没有照搬的桌面假设

- 没有再启动上游 Flask 服务或全局内存任务表，新模式接入现有 Django／PostgreSQL／Worker。
- 没有读取其他桌面应用的 DPAPI 配置、开发者登录态或 Windows 本机账号；没有复制 Windows Python、Node、模型权重和打包运行环境。
- 亿创文件下载只允许 HTTPS 公网目标，校验 DNS 后固定连接地址、保留 TLS 域名校验，拒绝重定向、私网地址和凭据转发；图片限制解码前尺寸与下载字节数。
- 网页抓取内核、捕获脚本和 Figma 插件源码与共同祖先相同，`url-capture.js` 仅品牌变化，并非本次新增功能。独立服务仍支持网页工程导入编辑与 Figma 格式导出，不把本机浏览器会话移植到远程服务器。
- 包内旧文档仍有“严格手动保存”等历史表述，与最新代码不一致。本次按实际新版行为合入自动保存，并保留可靠的未保存状态提示。

## 保留的拾界改进

公司 SSO、权限和 CSRF；每用户工程/任务/凭据隔离；任务取消、超时、中间结果恢复；原图及不可覆盖的历史版本；原生文字/矢量导出、Ubuntu 字体与字距适配；素材对齐、完整人物/边界检查、牌面文字忠实度、局部修复和可诊断失败分类。

上游新增复用只在同一实体且验收通过时启用，不能跳过已有质量检查。新助手生成的候选仍标记未验收，不能把“请求完成”当成视觉合格。

最终完整回归：151 项后端、117 项前端通过。逐项日志保存在本地 `.local/upstream-20261102/`，不包含于发布镜像。

真实 Codex 验收：

1. 流式分析完成并停在确认入口，理解耗时约 20 秒；不会仅因讨论触发生图。
2. 确认后生成独立灯笼透明 PNG：理解约 25 秒，生成约 83 秒，总计约 109 秒。候选主画布对比、下载、加入新层、撤销及重做均实际操作。
3. 自动保存后从工程库重开，原图、两层结构、黄色标注名称和保留要求仍在。测试工程命名为“美术新版验收 · 标注与灯笼候选”。
4. 实际下载 PSD，用独立 psd-tools 回读为 1024×1536、2 层；原图层与源 PNG 解码后逐像素一致。生成 PNG 为 1024×1024 RGBA，含 910961 个完全透明像素，标注未进入导出图层。
5. 指定清单拆层路径另跑一次，服务端 `assistant-split` 完成 1 个指定层：理解约 32 秒、生成约 82 秒。位置与比例仍需人工校准，候选已放弃，没有替换已保存工程；生成恢复记录保留。扩展画布登记不再把“同样画幅”当作已校准，界面明确提示待校准。

视觉判断：透明结构、灯笼部件与候选事务可用；独立素材仍有金属高光、花纹细节变化，指定拆层仍有配准问题。这两项不能记录为原图保真合格，也不代表复杂图稳定性验收已全部通过。

## 仍须明确的边界

太石与亿创当前没有在拾界配置可用于验收的真实账号，本次能验证协议、校验与隔离，不能声称这两条通道已经真实出图。原公司 Agent 的透明输出与附件编辑限制仍需真实通道持续验证。此前复杂素材批次尚未达到全部视觉合格；本次能力合并不能替代后续多图逐层质量验证。
