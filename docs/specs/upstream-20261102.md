# 美术版 20261102 合并规格

## 当前问题与期望结果

将美术交付的 `AI拆图助手_便携分享版_20261102` 新能力合入拾界 Ubuntu 多用户服务。以当前提交 `cd0f41d` 为回滚基线，以桌面原始便携版为共同祖先，做三方比较，不能用整目录覆盖丢失本地修复。

初始逐文件核对：108 个新增路径、66 个内容变化、67 个相同、3 个仅换行变化、14 个当前独有路径。新增路径包含开发源文件与运行副本，不能当作108项新功能。66个变化中，25项仅上游变化、15项仅拾界变化、26项双方变化。

## 保留契约

- 公司 SSO、授权、CSRF、每用户工程/任务/凭据隔离、持久任务及取消、超时和失败恢复。
- Codex 与原公司 Agent 均可用；现有自动模式配置优先级不被新增来源暗中改变。
- 原图、已有图层、工程版本冲突保护、撤销、原生文字/矢量导出、字体、保真与完整实体修复。
- 任务失败不自动重发收费请求；关闭页面不删除后台结果；候选确认前不覆盖工程。
- 不读取桌面开发者或其他应用的账号文件，不把 Windows 加密配置搬到 Ubuntu。

## 有意改变与范围

| 能力 | 预期可观察结果 |

| 指定拆层／再拆层 | 按清单顺序生成，不擅加背景；独立层原位分组，旧版本保留，不重设整个工程初始基线 |
| 提取、去件、背景与扩图 | 独立透明素材、标注删除、背景去UI、上下扩建、透明完整实体越界补绘及2:1参考创作，失败保留旧素材 |
| 理解与生图来源 | 保留现有连接并接入太石理解、亿创已适配的图片通道；每用户密钥加密、服务端调用、请求提交时固定选择 |

| 图层交互 | Alpha命中、低透明辉光、缩略图、侧栏调宽、宽工程库、统一助手与模型入口 |
| 后台并发 | 两个独立任务可处理并排队；保留账号互斥和同画布单任务，取消/重启不回填迟到结果 |
| 网页与外部导出 | 保留网页工程和PNG/SVG/HTML/PSD/Figma导出。追加祖先核对确认：网页抓取内核、捕获脚本、Figma插件均与祖先相同，非本次新增能力；沿用当前工程导入/导出范围，不另建服务器浏览器或复制登录会话 |

包内 BUILD/变更记录部分仍写“严格手动保存”，但最新 `studio.js` 和交接书已有自动保存；以实际行为及用户“全部新能力”的要求为准，并更新旧说明及相应测试。

## 结构与迁移约束

沿用“浏览器→Django→PostgreSQL/私有盘→Worker→独立任务进程”，把上游助手协议接入现有任务接缝，不启动第二套 Flask、内存任务字典或全局账号服务。上游界面源模块作为事实来源，构建同步运行副本；保留拾界的平台适配和已验证修复。第三方Windows运行环境、模型权重及打包产物不进入服务源码。

对账号/来源配置采用现有每用户加密与标准输入传递方式；不采用上游跨应用读取DPAPI配置的回退。并发由持久队列统一领取，账号冲突在排队阶段处理，不靠失败后重试。

不修改美术源目录或桌面基线。当前20个已保存工程建立哈希和副本基线。所有UI验收使用独立测试工程；不迁移或覆盖现有用户作品。当前Git提交可回滚代码，工程副本可恢复数据。只在无活动任务时切换Worker。

## 验收证据

1. 现有基线：140后端、112前端检查全部通过，日志 `.local/upstream-20261102/baseline-tests.log`。
2. 新协议覆盖身份/来源/标注/尺寸校验、跨用户拒绝、分析不生图、确认一次、取消和晚到候选、恢复数据及自动保存失败保护。
3. 浏览器实际操作标注、助手、候选确认/放弃/撤销、再拆层、自动保存/重开、缩略图及侧栏；运行产物与源文件一致。
4. 用授权的小案例验证已配置通道的真实分析和生成；未配置新通道采用协议检查并明确未完成真人账号验收，不能伪报可用。
5. 实际导出PNG/PSD并独立回读；标注不烘焙、完整实体不截断；检查20个旧工程哈希。
6. 完整回归在最后一次相关修改后运行；视觉保真另做逐层检查，不用测试数量代替画质验收。

## 风险与未知项

分享包排除了上游测试，交接书的556/113等数字仅是上游声明，不能算拾界验证结果。Windows启动、原生扩展、本机登录态及未配置太石/亿创的外部验收有平台/账号边界。新增保真提示和越界补绘不等于解决此前全部视觉失真，须用实际素材验证。

## 补充差异核实

`browser_capture.cjs`、`web_capture.py`、`capture.js`、`figma/code.source.js` 与最初便携基线字节相同，`url-capture.js` 仅品牌字样变化。这些出现在“新增路径”是因为独立服务最初未纳入便携桌面入口，并非美术新版新增功能。保持服务器范围，避免把本机浏览器访问权限搬到远程服务。

## 本轮结果

后端151项、前端117项回归通过；已实际验证标注、流式分析、两条生图路径、候选应用/放弃/撤销/重做、保存/重开及PNG/PSD导出。PSD原图像素一致，旧20工程哈希未变。太石/亿创真实账号、再拆层及所有图形工具逐一真人操作未全部覆盖，仍需后续专门验收；现有自动检查不能等价替代这些实测。详细结果与画质问题见 `../upstream-20261102-comparison.md`。
