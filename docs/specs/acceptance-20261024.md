# 拾界全功能实测与质量改进

## 目标

把已暴露给用户的功能逐项走通真实操作，保留可复查的截图、工程和导出产物。核心是可靠的原图分层、可编辑重建、局部修正、无损工程保存恢复和导出保真；不能以按钮能点、接口返回成功或自动测试数量代表视觉质量。

## 验收契约

- 原图分层：背景、独立对象、普通文字与简单矢量按内容拆分；完整素材不能挤进被遮挡的可见框。检查尺寸、位置、颜色、轮廓、透明边缘及前后遮挡。
- 图片生成与局部编辑：实际调用当前配置连接；限制区域外及未选对象不得被覆盖；取消、失败和重试保留已完成工作。所有产物必须是真实图片，不以空占位或假成功交付。
- 编辑：文字、几何、颜色、透明度、圆角、图层样式、锁定/显示、顺序、复制/删除、分组/对齐及撤销重做与画布显示一致。输入边界不产生坏工程。
- 工程：导入、另存副本、改名、手动保存、刷新恢复、跨类型打开、搜索、导出再导入都保留内容；冲突和失败不能覆盖旧版本。破坏性测试仅使用有备份的验收数据。
- 导出：图片与网页编辑分别覆盖所有展示格式和范围；检查真实文件尺寸、可编辑文本、矢量、分组、透明度、裁切、样式。无法现场验证的外部工具兼容性不得标为通过。
- 服务：公司登录、私有工程/任务/凭据隔离、权限边界、任务记录/取消/恢复及本地 Ubuntu 容器真实运行；不改其他用户权限或重置有效凭据。
- 交互：状态与实际能力一致，长任务有反馈，无死入口；菜单、键盘操作、缩放与画布边界可理解。必要改进沿用现有设计和原生平台能力。

## 范围及假设

包含图片工作台、已有网页工程编辑、工程库、AI 连接、任务及授权管理、部署自检。远程上线仍不在本轮授权范围；Figma 端、另一台设备、另一种凭据或不可用服务如无法实际运行，明确标记限制。AI 的视觉结果按实测样本评估，不承诺任意输入均达到像素级复原。新功能仅在验收发现明确缺口且有完整验证方法时加入。
