上传图片后手动开始拆分，首遍不自动逐件检查、返修或导出。继续拆分仅补未完成素材，保留已有图层及编辑；全部完成显示“拆分完成”。主动检查所选或精修后保留隐藏旧版本，可撤销；PSD 保留隐藏可编辑图层。修复层级依据原图遮挡调整顺序，不重新生成图片。

顶部“保存工程”更新浏览器工程库，“打开工程”进入工程库，库内可导入和导出外部工程文件。仅点击“保存工程”才更新浏览器工程库；导入、编辑、替换、生成阶段与取消不自动保存，已保存工程的后续修改也须再次手动保存。刷新只恢复最后已保存版本，未保存修改离开会丢失，页面会提示；旧工程库记录保留，不再自动裁剪20项。恢复不自动重新启动付费生成。作品统一在右侧选择画板或所选范围后导出。大工程采用图片去重传输与文件打包，原始图像字节保持，资源超限明确提示。

替换图片：未拆单图可直接替换整图或框选区域；拆分后选中一个图片素材，可整层或局部替换。支持文字描述、上传参考图及裁取参考区域；生成先预览，点击“应用替换”才修改，隐藏旧版并支持一步撤销。

“回到初始”恢复刚完整拆分成功的独立基准，随手动保存及工程文件保留；编辑、替换、精修、保存或重开不会重设。完整重新拆分成功才更新；旧工程缺少基准时禁用并说明。
