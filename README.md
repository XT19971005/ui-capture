# 拾界 · UI Capture

网页抓取、图层编辑与游戏 UI 分层工具。Designed by XT。

## 完整源码备份

- `拾界插件/开发源码`：网页与图像编辑器、本机智能拆图引擎、精修与工程恢复。
- `拾界插件/插件程序`：当前工作台构建产物。
- `技能包/game-ui-to-psd`：共享原生 PSD 导出与来源核验工具。
- `技能包/维护约定.md`、`技能包/同步到Codex.ps1`：技能维护与同步入口。
- `拾界插件/开发源码/分享打包`：便携包构建脚本、README 和搬迁检查脚本。

仓库根目录的 `edge` 与 `figma` 继续提供兼容网页插件入口。[源码说明](源码备份说明.md)。

## 下载便携包并使用

下载单独提供的拾界分享包，解压到固定文件夹后双击 `启动拾界.cmd`。源码备份不包含运行环境和本机注册配置，直接从源码运行需先配置对应依赖。Codex 账号由使用者在自己的机器上登录。

## 手动拆分与精修

上传、拖入、粘贴图片以及打开或恢复工程只加载数据。点击“开始拆分”才执行识别与素材生成；同一常驻按钮按状态显示“继续拆分”或“重新拆分”，处理中禁用。旧自动识别设置和图片修边控件、脚本已移除，原生图层及父组蒙版保留。

普通文字可编辑，纯色矢量、渐变、原生图层样式和可关闭蒙版保留。个别素材复核失败会标记待校对并继续处理后续素材，可导出标记 `NEEDS_REVIEW` 的 PSD。同源续拆只重新生成坏件和未完成素材，保留已通过素材和手动编辑。完整工程可精修文字、简单面板和纯色矢量，图片及父组保持不变。

## 工程保存与恢复

工程自动保存到当前浏览器的 IndexedDB，重新打开工作台可恢复最新工程。手动保存工程持续更新，自动保存最多保留20项；可导出工程文件和 PSD。服务器处理使用 RAM 与可清理的临时目录，源码备份不包含用户保存工程、图片、账号或生成素材。

生成质量仍需检查标记图层，源码备份不代表每张生成素材均已通过验收。
