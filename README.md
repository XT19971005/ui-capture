# 拾界 · UI Capture

抓取网页，编辑图层，导出设计。**Designed by XT**。

此仓库提供网页插件，下载后可以直接加载。图片自动拆分、本机 AI 引擎和模型不包含在此版本中。

## 安装到 Edge / Chrome

1. 点击仓库 **Code → Download ZIP**，解压到一个固定文件夹。
2. 打开 `edge://extensions`（Chrome 使用 `chrome://extensions`），开启「开发人员模式」。
3. 点击「加载解压缩的扩展」，选择解压目录中的 **edge** 文件夹，即包含 `manifest.json` 的目录。
4. 将「拾界」固定到工具栏，在目标网页点击插件图标。
5. 抓取本地 HTML 时，在扩展详情中开启「允许访问文件 URL」。

更新文件后，在扩展管理页面点击「重新加载」，再刷新工作台。保留安装目录和浏览器配置可避免工程存储随扩展标识变化。

## 使用

点击顶部「咕咕专注」可打开随插件附带的交互案例，支持新增／删除目标及专注计时。顶部「工程库／保存工程／打开工程」统一管理本地工程。


- **抓取范围**：当前屏幕（默认）、整页已加载内容、自定义框选。
- **图层编辑**：图层列表与画布选择同步，搜索、多选、分组、移动、缩放、对齐、吸附、锁定与隐藏。
- **文字与形状**：修改文字、字体、字号、字重、颜色、尺寸和圆角；双击画布上的文字编辑。
- **父子关系**：联动或独立操作；可设置是否裁切子级。
- **图片修边**：去背景、保留／擦除、边缘羽化。
- **工程库**：缩略图、搜索、重命名、副本、删除和工程文件下载。
- **导出**：全部画板或选中图层，可选 PNG、SVG、分层 PSD 和 Figma 插件数据。

常用操作：Shift 点选多层、空白处拖框、Ctrl+Z 撤销、Ctrl+Shift+Z 重做、Ctrl+D 复制、Ctrl+G 分组、空格拖动画布、Ctrl+滚轮缩放。

## 导入 Figma

1. 在 Figma 桌面版打开设计文件。
2. 在「插件 → 开发 → 从 manifest 导入插件」中选择本仓库 `figma/manifest.json`。
3. 在拾界中选择「导出 → Figma · 插件数据」，得到 JSON 文件。
4. 运行「拾界 · Figma 导入」插件，在插件窗口选择该 JSON 文件。

JSON 需要通过配套插件导入，不是可以直接拖入 Figma 的 `.fig` 文件。若 Figma 提示开发插件缺少 ID，请先在 Figma 创建一个开发插件，并将生成的 ID 填入 `figma/manifest.json` 的 `id` 字段。

## 工程存储

工程保存在当前浏览器、当前扩展的本地存储中。最近记录最多 20 个；主动「保存工程」的项目不参与自动清理。可在工程库「下载工程文件」保存 `.shijie.json` 备份，再从「打开工程」恢复。

清除浏览器数据、卸载扩展或更换浏览器配置可能使本地工程丢失。此版本不提供账号同步或云端存储。

## 还原范围

- 读取网页实际 DOM 和已加载样式，支持可编辑文本及常见形状。照片和复杂视觉效果保留为像素素材。
- 整页抓取仅包含已加载的内容；懒加载、虚拟列表、跨域 iframe、Canvas/WebGL 和受限图片可能无法完整还原。
- 复杂排版、未安装字体及特殊 CSS 效果可能有偏差；导出前请在工作台检查。
- 字体与形状尽量保留编辑能力，不能将任意截图自动变成完整可编辑网页。

## 文件

- `edge/`：浏览器插件，含已构建的 PSD 导出模块，可直接安装。
- `figma/`：配套 Figma 导入插件。
- `licenses/`：随插件分发的第三方库许可（ag-psd、svgpath、base64-js、pako）。

仓库不包含个人工程、测试素材、API Key、浏览器配置、开发依赖或 AI 模型。网页功能无需填写 API Key；图片资源可能按原网页地址请求读取。
