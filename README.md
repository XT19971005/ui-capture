# 拾界 · UI Capture

最新拆图知识与当前验证状态见 [ComfyUI拆图经验（2026-10-21）](技能包/ComfyUI拆图经验_20261021.md)。本次知识同步不包含生成图片、PSD、模型或安装包；完整知识的 API 传入验证仍待解决，不能视为美术验收通过。

网页抓取、图层编辑与游戏 UI 分层工具。Designed by XT。

上传图片后手动开始拆分，首遍不自动逐件检查、返修或导出。继续拆分仅补未完成素材，保留已有图层及编辑；全部完成显示“拆分完成”。主动检查所选或精修后保留隐藏旧版本，可撤销；PSD 保留隐藏可编辑图层。修复层级依据原图遮挡调整顺序，不重新生成图片。

顶部“保存工程”更新浏览器工程库，“打开工程”进入工程库，库内可导入和导出外部工程文件。仅点击“保存工程”才更新浏览器工程库；导入、编辑、替换、生成阶段与取消不自动保存，已保存工程的后续修改也须再次手动保存。刷新只恢复最后已保存版本，未保存修改离开会丢失，页面会提示；旧工程库记录保留，不再自动裁剪20项。恢复不自动重新启动付费生成。作品统一在右侧选择画板或所选范围后导出。大工程采用图片去重传输与文件打包，原始图像字节保持，资源超限明确提示。

替换图片：未拆单图可直接替换整图或框选区域；拆分后选中一个图片素材，可整层或局部替换。支持文字描述、上传参考图及裁取参考区域；生成先预览，点击“应用替换”才修改，隐藏旧版并支持一步撤销。

“回到初始”恢复刚完整拆分成功的独立基准，随手动保存及工程文件保留；编辑、替换、精修、保存或重开不会重设。完整重新拆分成功才更新；旧工程缺少基准时禁用并说明。

## 源码目录

- `拾界插件/开发源码`：编辑器、拆图引擎、工程恢复与分享打包工具。
- `拾界插件/插件程序`：当前工作台构建产物。

仓库根目录的 `edge` 与 `figma` 提供兼容插件入口。[源码说明](源码备份说明.md)。

源码仓库不含账号、凭据、本机配置、依赖运行环境、用户工程或生成素材。便携使用需单独下载完整分享包，在固定目录解压后运行 `启动拾界.cmd`；使用者在自己的电脑登录 Codex 账号。

初始扫描现在同时登记 UI 组件、底板/文字/图标/数值槽位、家族变体及复用候选，链接到实际图层。参考 Figma、Adobe、W3C、Material、Fluent、Carbon 和 Unity 官方资料整理的规则保存在技能中。相同素材与文字样式目前只登记候选，尚未自动共用生成结果或批量修改样式。

多选检查先判断是否为同一完整实体；经明确证据确认后可整体处理，未选图层保持，旧版本隐藏保留。规划补修只更新报错字段，不能用局部响应清空全图清单；失败的完整规划可保存并继续。无自身效果的初始组织组可按真实层序拆段，带蒙版/样式/透明度的组受到保护。

测试覆盖结构、操作与文件完整性；真实生成素材的画面质量需具体检查，组件关联成功不代表文字识别、轮廓或整图视觉验收通过。

本轮新增框选区域检查：先确认完整图层名单，只处理勾选范围，未选内容保持；画布右键及Alt单击支持选择遮挡图层，75层工程使用图片缓存与增量预览。实际网页区域单层流程、范围外数据、移动和撤销已验证；不代表整图质量通过。
