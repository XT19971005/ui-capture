拾界 UI Capture — Designed by XT

运行入口：双击 启动拾界.cmd。本机网页 http://127.0.0.1:19217/image-editor.html。
固定扩展目录 插件程序/edge 不搬动；分享时解压整个拾界便携分享包。

功能
- 网页编辑：输入网址按 Enter，后台打开真实 Edge 页面并抓取。打开网页按钮用于登录或交互。
- 图片拆分：用户自己的 Codex 识别布局/文字，复杂素材实际生成补全，逐步显示已完成图层。
- 完整拆分后的精修只改已有原生文字、简单面板和纯色矢量；图片、背景及图片父组保持原样。
- 两种模式共用选择、平移、缩放、分组、对齐、撤销、回到初始和图层滚动定位。
- 自动 PSD 必须完成实际逐层复核；仍有问题时标为“待校对”，可下载已审计 PSD，不代表验收通过。人工逐层确认单独记录为手动校对。

存储与分享
- 浏览器工程库按同一工程 ID 自动保存并恢复最新图层；手动保存工程持续更新，最近自动记录保留 20 条。
- 任务临时素材与检查文件在结束后清理；主动下载工程文件可另作备份。工程库保护既有手动记录与正式交付。
- 随包 Windows x64 Node/Python 3.10 和必要依赖，不含本地 AI 模型或账号凭据。
- 其他人使用自己的已安装/登录 Codex。连接按钮检查当前电脑的 Codex；账号留在 Codex。
- runtime.local.json、模型、缓存、测试素材、交付与运行状态不进入分享包。

维护
- 开发源码/工作台增强：共用编辑交互、工程库与排布。
- 开发源码/图像重建：图片场景、前端任务与原生导出。
- 开发源码/自动拆图：本机服务、Codex、ImageGen、复核与 RAM 结果。
- 开发源码/网页抓取：真实浏览器网页抓取。
- 开发源码/文字排版：共用文字测量。
- node 开发源码/图像重建/构建模块.cjs 同步模块到固定 edge 安装目录。
- 验收证据在工作区 测试结果，正式图片项目在 交付包。
- iframe 内部、无限滚动或必须登录的页面需按实际状态核验，不能保证任意网页完整抓取。
