# 完整组件执行分支（components-v1）

通过QPAutoPSD的绑定方案运行，所有图像处理和PSD导出发生在服务器ComfyUI。Codex当前为人工规划者，不冒充服务器自动视觉专家。

支持按z序执行source、edited、biref、shape、solid、text，使用裁紧RGBA与原图坐标。多边形、孔洞与子层清除区域显式登记；edited复用已连接Klein模型补绘，非无损恢复。原生文字字体为近似字体；渐变/材质区域不能当纯色形状。

局部修复的遮罩外像素不变只证明范围正确，不证明内部画面合格。容器必须单独看图，不能因全图叠回后遮住残留就通过。邻近复制修补须检查色彩、纹理和接缝；大范围inpaint可能延续原彩色填充或留下抹除痕迹。

原生分组按连续绘制段建立，不能将非连续层强行聚合改变遮挡顺序。当前尚未实现全自动完整实体补全和自动美术验收，同款复用仍需底稿真实验收。

验证：108项本地回归、独立PSD分组回读及本图64项数据路径受控测试通过；受控测试不调用真实生成，不证明本图美术通过。实际07轮运行完成，65层/9文字层为服务器报告；PNG实际检查未通过，PSD本地下载未完成。
