# precision-v1 分支

通过现有QPAutoPSD节点的plan_json调用。保留原图像素摘要、宽高与完整素材清单，新增pipeline=precision-v1。所有assets显式指定唯一整数z（由后向前）、整数像素box和method。节点在服务器完成处理和原生PSD组装，不依赖本地PSD后期修改。

方法：biref复用显式传入的开源抠图模型；panel按box/fill/radius/border/border_color/inner_shadow重建完整无孔底板；glyph_effect依据background_color及effect_color分离深色RGBA效果与白色原生形状；yellow_matte对白色/蓝色背景中的黄色装饰拟合局部底色、估算软Alpha并去底；white_matte通过已知背景色恢复白色软素材。

这些是有约束的确定性近似，不是通用语义分割模型。颜色去底依赖前景与背景可分；复杂多色背景、交叠物体、阴影与孔洞仍须看图。重建面板不等于恢复原始设计参数。原生形状不等于原生文字；云、署名和人物仍组合时须明确待拆，不能把新层数或接口成功当验收。

本地93项回归覆盖已有行为及面板无字孔、软Alpha去底、显式层序与重复层序拒绝。真实海报的画面验收独立记录。
