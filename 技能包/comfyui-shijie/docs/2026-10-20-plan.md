# ComfyUI 拾界原生分层 Implementation Plan

> Execute inline with executing-plans. User approved reuse of existing text/vector/PSD capabilities in ComfyUI.

**Goal:** ComfyUI 内将千问 RGBA 图层、OCR 与原生文字/纯色矢量重建连接为可审查 PSD。
**Architecture:** Python V1 custom nodes consume IMAGE tensors and structured JSON, preserve alpha, use CPU OCR and existing Bezier fitter. A vendored pure-JavaScript ag-psd writer emits editable text/shape metadata and explicit merged preview + JPEG thumbnail. No Windows-only canvas binary and no external SaaS.
**Tech Stack:** Pillow, NumPy, OpenCV, SciPy, RapidOCR ONNX (optional until automatic OCR is used), Node.js, ag-psd/svgpath.
**Spec:** User-approved flow in chat: upload → analysis → layering → editable text / pure-color vector → PSD. PNGs and PSD share one named project folder. Existing images remain the test source.

## Constraints
- No changes to credentials, existing workflows or unrelated skills. No automatic paid API calls.
- Fonts must be explicitly available; unmatched font is reported, never claimed as exact match.
- Low-alpha shadows are valid layers; only opaque flat-color candidates may become shapes.
- IMAGE RGBA is preserved; RGB + MASK uses ComfyUI mask semantics (1 means transparent).
- Output stays under ComfyUI output directory, names are sanitized, repeated runs create new project directories.
- Installation happens only after the package and tests are reviewable. Shared-server deployment and local proof are reported separately.
