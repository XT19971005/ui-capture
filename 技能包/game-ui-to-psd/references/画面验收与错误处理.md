# 实际看图和验收

## 16项基本验收标准（2026-10-14）

每项必须填写PASS/FAIL及真实观察。不能只写“正常”或因导出成功全填PASS；未看清、缺证据或重大问题未修复不得交付最终通过状态。

1. 拆分粒度：不同图片、人物、道具、图标和装饰独立成层；功能区/父组不压成一张位图。仅无法独立提取的互遮完整实体可组合，说明原因。一体人物与材质内文字不碎拆。
2. 文字合并边界：只有视觉相连、语义同一的连续文案合并，保留换行与局部样式；不同按钮、标题/副标题、标签/数值和独立位置的文案分别编辑，不机械按像素接触判定。
3. 画布与比例：核对原图尺寸、宽高比、人物与控件比例，不拉伸、不变形，不因补全缩放主体现有可见区域。
4. 位置与层级：坐标、旋转、间距、对齐、遮挡和堆叠顺序正确；无重复覆盖、轮廓叠加或错层。
5. 颜色与光照：逐层肤色、头发、服装、品牌色、色相/饱和度/明度/色温及高光阴影与原图一致；不增强、加艳、美白或重布光。
6. 人物身份与完整实体：脸型、五官、发型、神态、姿势、衣物、持物准确；关闭蒙版后完整，独立角色不串脸或漏件。
7. 文字内容与字形：逐字核对中英文/数字、标点、年份，核对字体、笔画、孔洞、方向、间距、基线、裁边；模糊处找清晰同款或记录推断。
8. 文字原生编辑：普通文字为PSD原生文本且与显示一致；艺术字/纯色字形可以轮廓矢量，材质内文字保留素材，不把位图冒充可编辑文本。
9. 矢量完整与孔洞：纯色控件/标识为真实路径，正确减孔与保留内部文字岛，平滑曲线无新增锯齿毛刺；原有笔刷纹理保留。
10. 透明边缘：无相邻物品/背景残留、白边/彩边、破洞、毛刺、矩形接缝，白色皮肤/牌面/布料不误透明。实际查看深浅底。
11. 背景去件与补全：背景无人物、UI、文字或阴影残留，补绘连续且风格/原光照正确，推断区如实注明。
12. 渐变与图层样式：原生渐变色标/方向/尺度及描边、投影、内阴影、发光、颜色/渐变叠加存在且可开关；用户允许轻微渲染器差异，不能丢主要效果或改变主色。
13. 蒙版与完整底稿：蒙版开启显示正确，关闭后完整底稿仍在；父组作用范围正确，源RGBA不因效果或蒙版被破坏。
14. 来源与独立回读：完整素材SHA和RGBA一致；检查图绑定本次PSD，不用旧图/缓存冒充回读，不自动更新哈希掩盖坏素材。
15. PSD编辑与重组：实际原生文字/矢量/样式/蒙版描述存在，独立层与整体合成正确，移动/开关后对象完整；用户主动点击下载时核对文件字节与审计PSD一致。未在Photoshop实测时如实说明；需安装的字体说明，不谎称嵌入字体。
16. 完成状态与清理：首遍生成标未检查，继续拆分只补未完成项；用户主动检查或正式验收时记录实际复核，网页模式保留具体待校对项，只有用户主动点击才导出结构已审计PSD；只有全部实际复核通过才记PASS。处理中/失败不得当最终通过。网页临时图和工作目录按成功、失败、取消清理，手动保存和正式交付保留；实际完成清理前不能写已清理。

用户主动检查或正式验收时，逐件6项（身份与完整实体、比例与定位、颜色与光照、透明边缘与孔洞、材质文字与标识、独立物品归属）先对照原图和深浅底独立素材，再进行上述最终16项验收。每件最多自动返修一次；仍不通过则标记该件待校对并继续其他件；源裁切占位必须标待提取，不能降低标准写PASS或重复收费无限重试。继续拆分只补未完成项，主动修正只处理有完整失败证据的已选项；已有完成素材保留同源字节及用户手改。回归测试中的mock只用于复核门槛，不代表模型生成质量已验收。

自动结构通过后，必须实际读取图像。不能只创建检查图文件而不打开，也不能仅查看统计、缩略文件名或 cached composite 后宣称自检完成。

## 必须实际检查

- 完整人物：浅色、深色、棋盘格；脸、帽带、持物、衣袍、肢体没有缺口；角色里不含标题、日期、边框、徽章或背景块；边缘没有橙色污染或硬接缝。
- 人物局部放大：保存原图、独立素材浅底、独立素材深底的并排对照，在原显示尺寸及至少 2 倍放大检查头发/脸、肩部、双手/手指、服装折痕、帽带、持物和脚。不能只看全人物缩略图；配准特征点多、像素同源也不能证明局部未重绘。发现明显漂移先返修，不把身份、表情或衣纹变化作为一般「材料差异」通过。清理只针对拆分新增的残点和边缘色污染，保留自然发丝、毛绒和真实衣纹，登记最终同源 RGBA 后不再悄悄改写底稿。
- 完整背景：没有人物、袖口、帽带、文字、控件残留，遮挡区补绘连续。
- 艺术字：单独逐字看笔画。移动或关闭旗子、人物后字必须仍完整。
- 年份和标识：逐个数字检查；保留孔洞与孔内文字，不能只看最终被人物挡住的合成。
- 模糊小素材：核对识别出的文字、英文副标题与品牌版本；重建后在原显示尺寸和放大状态逐字查看，不能只检查阈值轮廓或缩放一致性。
- 矢量边缘：按原图比较实际轮廓。平滑图形应没有拆分新增的锯齿和小凸点，必要时重拟合曲线；原图有意的毛边、笔刷和手工风格则保留。不要靠模糊显示缓存掩盖坏路径，也不能把原本的艺术毛边抹成圆滑字体。
- 文字与控件：实际文案、位置、颜色、原生编辑描述和显示缓存一致；需要时在 Photoshop 实测编辑。
- 整体：原图与独立合成对照，检查相对位置、尺度、行距和遮挡。模型若改变人物身份、姿势或衣纹，返修素材；不要贴原图碎片伪装还原。

各独立 PSD 图层在 `03_检查/独立图层`；整个人物、艺术字和背景回读另有对应 PNG。检查工具不会把这些图发布到聊天。

## 记录和门槛

`run` 在统一 PowerShell 入口下会创建 `03_检查/画面复核.json`，所有项目初始 PENDING。agent 真正查看后逐项记录观察和 PASS/FAIL，再运行 `review-check`。

`review-check` 验证记录绑定的 PSD 与检查图片是否还是当前版本、结构与素材检查是否通过、是否有未处理问题。它不能判断 agent 是否真的看过图，也不能自动代写“全部正常”；这一点由执行本技能的 agent 负责。

重建 PSD 会使此前画面记录过期。脚本永远不凭结构检查自动通过画面验收。用户要求只放文件夹时，不在最终回复贴检查图，只给输出路径、完成的验证和仍存在的材料差异。

## 出错后的顺序

1. 读取用户指出的实际文件，查看对应素材、单独 PSD 图层及原图；不要先猜缓存或用户开错了文件。
2. 沿素材来源、准备脚本、导出器、实际 PSD 查到出错阶段。先复现坏版本被拒绝，再修正确来源。
3. 原失败文件归档；修生成脚本而非只覆盖一次成品。复查同类其他对象。
4. 修后再次回读并实际看图；不靠降低阈值或更新底稿哈希强行通过。

已出现过的错误：完整艺术字被遮挡轮廓裁坏；人物原图 RGB 套进另一张 alpha 导致背景和文字污染；孔洞操作最后减掉内部标识文字；人物 alpha 从年份中相减导致首个数字残缺。集成测试覆盖这些行为及未实际看图时不得通过验收。

原图有渐变的对象逐项登记并保留；信息条、大标题、姓名板、金属边框和发光图标不能简化为纯色。检查 PSD 原生色标、方向、缩放，原生文字的渐变用可编辑图层样式。透明 PNG 中 alpha=0 的 RGB 不能当成残片；必须在棋盘格及深浅底实际查看。


显示蒙版和图层样式允许使用，完整性约束针对底稿。实际检查最终显示及关闭蒙版/样式后的完整素材，分别登记用途和推断。详见 [海报拆分实战复盘](海报拆分实战复盘.md)。


## 证据完整性与PSD边界（2.34）

组件/实体误合并、变体串色、AA碎层、孔洞微点、浅色前景和多行字形的复核场景见[UI元素与结构知识](UI元素与结构知识.md)。以实际画面逐项作证，官方分类、规划元数据和离线回归都不能自动提升艺术质量状态。

- 规划校正核对原清单与稳定ID：按原序只修报错字段，保留全部原条目、有效值和来源，局部缺省或空数组不授权删除。辅助UI候选重编保留旧版，不阻断有效绘制项；素材框按planner取整后宽高检查，均至少8px。失败保留完整planningDraft，显式继续仅补修、不重新首扫；草稿已被用户编辑则在模型调用前拒覆盖。异常保留最后有效规划，生成结束不等于原图已完整分层。
- 规划解析不得静默漏掉非法项后宣称完成，也不按大面积排除合法主体。显式art_text_ids逐项检查实际绘制表示，缺失才按原bbox/z补艺术字资产；纯组织group连续段重编只限规划补修且无mask/style/opacity等外观影响，须证明节点内容/绘制顺序不变，普通resume禁止。draft组装及UI映射resolved仅证明结构；位图仍待生成时不能算画面验收。
- 逐件或最终复核先校验类别齐全且唯一、观察非空、检查图片与当前PSD对应。缺项/重复/空观察是复核未完成，不能伪装成素材FAIL、触发收费重画或替换已有像素；重试复核与重新生成分开判断。
- 隐藏旧版和普通隐藏层必须仍存在于PSD，逐层来源校验不省略。独立内容回读可忽略显隐，整图合成则继承自身及祖组显隐；不能用独立图可见证明整图应该显示，也不能因整图隐藏跳过完整底稿检查。
- 同源RGBA零差异只证明导出忠于当前生成底稿，不证明底稿与原图的OCR、字形、云形或前景分离正确。半像素定位只采样一次，源SHA与既有容差不因校验失败而改；修改RGB、alpha、几何或源文件的负例必须被拒绝。
- 导出检查绑定点击时的脱离引用快照与实际PSD；导出期间后续编辑不混进文件，后台运行scene及新完成图层不被旧导出改写。
- 旋转/多行文字检查正常字形轴和原生文字描述。基础渐变、已观察到的字形描边与外部图层效果分开核对：关闭外部效果不应关闭基础填色/描边，外部参数及关闭状态仍可编辑。
- 阴影/发光原生描述、开关与渐变独立回读分项记录；psd_tools未完整绘制的效果明确保留读器边界，不把描述存在当Adobe客户端渲染或真实生成画面已通过。


## 标签恢复与网页操作反馈（2.34补充）

- 刷新分别核对各标签已保存ID及库内最后手动保存的图层；未保存的新导入不得覆盖原保存指针，保存后继续编辑不得自动改写库记录，不能只证明全局最近工程能恢复；sessionStorage不保存图片。记录缺失/类型不符、主动关闭、新标签默认与短暂读库失败分别验证。
- 通用长状态不等于拆分失败；切工程后旧拆分反馈清除，旧工程异步导出通知不能写到新工程，复制按钮在忙碌结束后重新计算可用状态。
- 本用户已明确停止主动下载PSD，网页验收也不代点下载；发布后仅用户点击才导出。离线PSD编码与回读可以证明各自边界，不以此补写真实网页下载或真实生成画面通过。
- 报告删除不存在的下载入口提示；前景素材计数不含隐藏旧版或背景，背景不得称为透明素材，避免把节点总数当有效前景数。
- 多行fallback逐行度量并保留来源框锚点，细渐变背景近色聚类后继续字形拟合。字号/坐标的拟合改善及专项回归，与新生成图逐层视觉验收分别报告；运行中的真实文字精修未结束不写结果。

- 实际画面中独立前景被烘焙进背景属于分层缺陷，不能因主体来源校验、续拆完成或离线测试通过而放行；修复通用规划不等于已经修好旧工程。真实联合选集诊断遗漏或越权检查图片时明确记未成功，保留旧工程；离线专项和只读规则评估不替代网页修复成功与实际画面验收。


## 局部替换、手动保存和初始基准（2.36，2026-10-16）

- 分别验收未拆单图直接进入与拆分后选择一个图片素材；整层、局部选区、参考图裁取均用自然图片像素，缩放、边界与非法框需独立验证。文字描述或参考图至少一项；导入原图锁例外不得越过普通图片层及祖组锁。
- 生成只返回候选，预览时当前工程不变；应用后保留隐藏旧版且一步撤销。核对目标几何、蒙版、父组、未选层与选区外RGBA保持；失败、取消、晚到响应、输入修改或切工程使候选失效，不能串工程或覆盖新编辑。
- 对导入、移动、替换、精修、阶段进度、失败、取消、切换、关闭和flush逐项确认没有工程库写入。明确点击“保存工程”后重开得到点击瞬间版本；保存后再编辑仍显示未保存且不覆盖库记录，配额/冲突失败必须保留RAM并报告失败，旧回调不能误标新工程已保存。旧自动记录保留，不再执行20项裁剪。
- 完整拆分成功才建立独立基准；移动/替换/精修/保存/重开后“回到初始”仍得到刚完整拆完的版本，恢复可撤销。重新完整拆分成功才更新基准；未完成和旧工程缺失/损坏基准时明确禁用，不以当前状态冒充。验证工程库与工程文件往返、图片去重、基准不递归且不进入模型传输。
- 基准缓存按工程ID与基准对象身份失效，不能每次交互深克隆完整工程；指针移动热路径不调用整工程保存或序列化。缓存调用计数/离线性能断言不是浏览器帧率。
- 真实生成的内容、选区接缝和参考图使用效果须实际看图；区域外字节正确不证明区域内艺术质量。未跑真实网页或付费生成时如实列出，不能用受控响应冒充通过。本轮仍不主动下载PSD。
