# 项目清单与素材来源

组件家族/变体/实例、完整实体、字标孔洞与抗锯齿、前景和九宫格的判定依据见[UI元素与结构知识](UI元素与结构知识.md)。语义关联不替代本清单的实际节点和完整来源；共享候选不能把多个实例合成同一实体。

`init` 自动记录输入尺寸并生成 `02_结构/项目.json`。不要沿用上一张图的画布、坐标或文字。项目中的 `layers` 和每级 `children` 按由下到上绘制，前景遮挡物排在被遮挡素材上方。

## 完整 PNG

运行 `register` 后使用返回的 spec；文件原样复制，登记结果在 `02_结构/素材登记.json`。登记只证明文件及透明度，不证明视觉合格，必须先实际检查素材。

- `role: character`：完整人物底稿；新项目 `enforceCompleteSources: true`，人物必须登记来源。多个独立角色可作为普通 bitmap，另保留一个完整组合对照作为 character。
- `role: artwork`：完整艺术字；必须固定 `completeAssetSHA256`，不能提供另一张显示 cache 或添加蒙版。
- `completeAssetSource: {file,sha256,transform}`：原始完整 RGBA、固定哈希、Canvas 六元素变换 `[a,b,c,d,tx,ty]`。导出和 verify 都检查整体定位后的像素，回读 PSD 再与源底稿渲染参考比对。
- `file / x / y / width / height`：最终完整位图和整体位置。颜色与 alpha 一起缩放；不能用原截图 RGB 覆盖它。
- 角色分层时若整张底稿是一个相互遮挡组合，保留组合即可；不要为增加层数拆成脸、手和衣服碎片。

来源参考 PNG 在 `03_检查/完整底稿参考`，来源检查记录绑定当前项目清单及 PSD 哈希。不能用过期结果完成新版本的验收。

同源RGBA比较与PSD显示缓存必须从同一原始完整底稿、同一定位变换各渲染一次；尤其半像素坐标不能对已经重采样的缓存再次重采样。保留源文件SHA和既有容差，用改RGB、改alpha、错几何及重写源文件SHA的负例验证拒绝，不能为通过而换底稿或放宽门槛。

## 普通文字

`kind: text` 使用 `text.value / family / postscript / size / color / x / y`，可设置 baseline、targetWidth、描边。字体 PostScript 名称与实际字体一致；在项目 `fonts` 中登记额外字体。

已有 `cache` 必须同时提供 `native.text`。修改文字内容或字体时刷新显示缓存；缓存与编辑描述不一致不能交付。特殊艺术字保持完整纹理 PNG，不能用普通字体替换。

多行fallback以逐行字宽、最长行和行高测量，不把换行串成一行；保留原来源框锚点，单行带留白也不擅自重新居中。背景近色渐变作为同类材料聚类后继续字形拟合，不因细微色阶直接跳过；拟合结果仍核对实际墨迹和原生文字描述。

## 纯色矢量与提取

`kind: shape` 使用 `color` 与 `d`，复杂形状用 `shapes: [{d,operation}]`。原生描边、渐变可保留原生描述；普通参数支持线性渐变。

- `combine` 添加形状，`subtract` 减去孔洞，孔洞中的文字岛随后再 combine。
- SVG even-odd 的缓存效果不能自动等同于 PSD 中每条 combine 路径。树层级必须正确；原生回读合成须检查。
- 路径坐标使用画布像素，Bezier 不再除以画布尺寸。
- 完整年份不能减去人物 alpha；原图有完整数字就直接提取，缺笔画先补全几何。

`trace` 接收 `--regions` JSON 数组，例如：

```json
[
  {"name":"完整年份","box":[2593,625,3148,780],"mode":"cream","color":"#f2e2a5","keepLargest":4},
  {"name":"联名标识","box":[2660,408,2950,608],"mode":"brown","color":"#772a16"}
]
```

坐标只是案例，须按当前图填写。可用 `rules: {r:[最低,最高],g:[最低,最高],b:[最低,最高]}` 自定义阈值。`keepLargest` 仅在已确认实际对象数量时使用，不能盲目删除标识内部小字；`pixelScale` 提高细线和尖角的像素面积精度。

输出 `02_结构/矢量分析.json`，包含原生 shapes 和 `integrityRegion`。轮廓提取不会识别身份、自动找字或补全遮挡；必须实际查看。原图存在被遮挡部分且已补全时，在说明中记录依据，不能直接拿受遮挡的原图颜色遮罩覆盖完整矢量。

独立浅色/大面积前景依实际边界与遮挡登记，不按底部位置、面积或颜色误归背景；明确纯色可保留原生矢量，按真实z_index与完整角色交错。生成干净背景的去件清单包含前景矢量的来源ID、几何和层序；无证据不新增前景平面，也不自动修改既有工程。

## 当前支持边界

支持 normal 混合、普通位图、原生文字与形状。复杂混合、剪贴组未实现时明确报错，不能静默输出近似效果。输入大于 1200 万像素会阻止导出；不得自行缩小用户原图而不说明。迁移环境只改运行配置，不搬插件依赖或修改输入素材库。

## 完整底稿加父组显示蒙版

父组可以填写 displayMask 对象：d 为画布坐标路径，reason 为显示遮挡用途，disabled 为可选关闭状态。子层仍按完整底稿或完整矢量编码。导出原生组蒙版，开启时按路径显示，关闭后子层完整内容恢复；不得在子层 RGB/alpha 中烘焙遮罩。父组蒙版不改变完整素材来源检查。父组与叶层蒙版的原生描述、开关及离线回读已专项验证；复杂剪贴链与Photoshop客户端实际编辑仍未验证，不能扩大为完整客户端渲染通过。


## 网页工程事务与嵌套组（2.34）

- 工程导入/导出保留完整元数据、原图、隐藏旧版和待完成节点；重复图片共享字节，内部恢复引用标记与同名用户字段无损转义。文件下载不等于库内保存。
- 同ID保存/删除排队并在事务内比较持久版本。只有实际提交的删除/淘汰证据可授权空记录重建；保留轻量旧版本标记，不把远程新revision当成旧内容的保存基线。自动库保留本次提交与其他最近19项，手动工程不被裁剪。
- 成功/错误提示检查同一工程对象与ID；保存期间的新编辑仍属未保存，写失败保留RAM并明确失败，不能由旧回调给新工程标成功。
- 组树是复制、删除、分组、排序和PSD层序的共同依据。复制整树重映射ID；删除清理全部后代及失效引用；同父级移动保留子树、蒙版和锁，不按扁平nodes顺序拆散组。
- 解组保留祖组蒙版及原有子树顺序；组自身的蒙版、不透明度、隐藏或效果不能无损移交时明确拒绝，不静默丢弃外观。

- 每标签在sessionStorage仅保存{id,kind}，按该ID恢复库内最新scene；缺失/类型不符明确留空，关闭写空指针，新标签才选择同类型最近工程。导入/保存/切换/关闭维护指针，临时读库错误保留重试目标，旧查询不能覆盖新工程。

- 验证旧版标签时先明确打开当前工程建立指针，再分别刷新核对，不能倒推旧版本从未保存过的标签指针已存在。实际取消→刷新→续拆需比较既有节点完整对象、图片字节、父组及成员顺序，不只比较层数。
