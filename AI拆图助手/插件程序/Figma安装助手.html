拾界 · Figma 插件安装

JSON 是页面数据，需要通过「拾界 · Figma 导入」插件读取。

  1. 使用 Figma 桌面版，打开一个 Figma Design 文件。
  2. 菜单 → Plugins（插件）→ Development（开发）→ Import plugin from manifest（从 manifest 导入插件）。
  3. 选择本包 figma/manifest.json。
  4. 菜单 → 插件 → 开发 → 拾界 · Figma 导入。
  5. 在插件里选择导出的 JSON，点击「导入到当前页面」。

如果提示缺少插件 ID

在 Figma「插件 → 开发 → New plugin」创建一个名为「拾界 · Figma 导入」的插件，选择 Figma Design 和 Custom UI，并保存到一个临时目录。然后在这里选择它自动生成的 manifest.json，生成带你自己 ID 的安装文件。

下载后，用它替换本包 figma 文件夹内的 manifest.json，再从 Figma 导入此文件。不要替换 code.js 或 ui.html。
